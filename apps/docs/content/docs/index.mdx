# Welcome to Thalamus

Thalamus is a visual diagram editor for event-driven architecture modeling with React Flow.

## Features

- **Visual Editing** - Drag and drop nodes to create your architecture diagrams
- **Rich Node Types** - Ideas, questions, evidence, goals, and more
- **Real-time Collaboration** - Share and collaborate on diagrams
- **Export Options** - Export to PNG, SVG, or JSON

## Getting Started

1. Visit [app.thalamus.sh](https://app.thalamus.sh)
2. Create a new diagram or use a template
3. Add nodes and connect them with edges
4. Share your diagram with others

## Tech Stack

- **Frontend**: React 18, TypeScript, Vite, React Flow
- **Backend**: Cloudflare Workers, Hono, Cloudflare D1
- **Auth**: BetterAuth (email/password + OAuth)
