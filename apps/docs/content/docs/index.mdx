# Welcome to Thalamus

Thalamus is a visual diagram editor for event-driven architecture modeling. Build and visualize complex system architectures with an intuitive drag-and-drop interface.

## What is Thalamus?

Thalamus helps you:

- **Visualize** event-driven architectures with clear, organized diagrams
- **Model** complex systems using intuitive node and edge representations
- **Collaborate** by sharing diagrams with your team
- **Document** your architecture decisions in a visual format

## Tech Stack

Thalamus is built with modern technologies:

- **Frontend**: React 18, TypeScript, Vite, React Flow
- **Backend**: Cloudflare Workers, Hono, Cloudflare D1
- **Styling**: Tailwind CSS, shadcn/ui
- **Auth**: BetterAuth (email/password + OAuth)
