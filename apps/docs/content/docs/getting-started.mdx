# Getting Started

This guide will help you get up and running with Thalamus in just a few minutes.

## Prerequisites

Before you begin, make sure you have:

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- An internet connection

## Creating Your First Diagram

### Step 1: Access Thalamus

Navigate to [thalamus.sh](https://thalamus.sh) in your browser.

### Step 2: Create an Account (Optional)

While you can use Thalamus without an account for local diagrams, creating an account enables:

- Cloud storage for your diagrams
- Sharing capabilities
- Cross-device access

### Step 3: Start a New Diagram

1. Click **"Get Started"** or sign in to your account
2. From the dashboard, click **"New Diagram"**
3. You'll be taken to the editor canvas

### Step 4: Add Your First Node

1. Right-click anywhere on the canvas
2. Select the node type you want to add
3. Click to place the node

### Step 5: Connect Nodes

1. Hover over a node to see connection handles
2. Drag from one handle to another node's handle
3. Release to create a connection

## Editor Controls

| Action       | Control                           |
| ------------ | --------------------------------- |
| Pan canvas   | Click and drag on empty space     |
| Zoom         | Scroll wheel or pinch gesture     |
| Select node  | Click on node                     |
| Multi-select | Hold Shift and click              |
| Delete       | Select and press Delete/Backspace |
| Undo         | Ctrl/Cmd + Z                      |
| Redo         | Ctrl/Cmd + Shift + Z              |
