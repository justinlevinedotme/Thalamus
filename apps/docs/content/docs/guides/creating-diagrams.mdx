# Creating Diagrams

This guide walks you through creating your first diagram in Thalamus.

## Adding Nodes

1. Click the **+** button in the toolbar to add a new node
2. Choose a node type (Idea, Question, Evidence, etc.)
3. Click on the canvas to place your node

## Connecting Nodes

1. Hover over a node to see connection handles
2. Drag from one handle to another node
3. Release to create the connection

## Node Types

| Type     | Purpose                         |
| -------- | ------------------------------- |
| Idea     | Represents a concept or thought |
| Question | Something to explore or answer  |
| Evidence | Supporting data or facts        |
| Goal     | Desired outcomes                |

## Keyboard Shortcuts

- `Ctrl/Cmd + Z` - Undo
- `Ctrl/Cmd + Shift + Z` - Redo
- `Delete` - Remove selected nodes
- `Ctrl/Cmd + C` - Copy
- `Ctrl/Cmd + V` - Paste
